# Deploy

Kubernetes manifests and Helm charts for deploying Kuvera to a cluster.

## Layout

```
deploy/
├── helm/           # Helm chart(s) for production and staging deploys
└── manifests/      # Raw Kubernetes manifests (dev cluster, CI)
```

## Quick start (dev cluster)

```bash
make dev-cluster     # boots a kind cluster with eBPF support
make deploy-dev      # installs the Helm chart to the dev cluster
```

## Helm chart

The `helm/kuvera/` chart installs all Kuvera components into a single
namespace. Values files for different environments live alongside the chart.

## Manifests

`manifests/` contains raw YAML for ad-hoc dev and CI use: the sensor
DaemonSet, RBAC resources, and CRD definitions. These are also generated by
the Helm chart, but raw manifests are useful for `kubectl apply` during
development.

## eBPF requirements

The dev cluster (kind) must have:
- BTF available at `/sys/kernel/btf/vmlinux`
- `/sys/fs/bpf` mounted into nodes
- `/sys/kernel/debug` accessible

`make dev-cluster` configures this automatically via `deploy/dev/kind-config.yaml`.
